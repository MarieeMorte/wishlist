# Wishlist

Вишлист с ценами на товары из Wildberries, Ozon и Яндекс Маркета.
Бэкенд на FastAPI, БД — PostgreSQL, фронт — ванильный HTML/JS.

## Запуск

1. Скопировать `.env.example` в `.env`.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Создать БД PostgreSQL (пользователь `wishlist`, база `wishlist`).
4. Запустить: `uvicorn app.main:app --reload --app-dir src`.
5. Открыть http://localhost:8000.

## Как пользоваться

1. Добавить товар: название, приоритет, целевая цена (опционально),
   заметка, и одна или несколько ссылок с маркетплейсами и ценами.
2. Товар появится в списке, сгруппированный по выбранному критерию.
3. На карточке под каждой ссылкой можно обновить цену — она
   попадёт в историю и повлияет на сортировку.
4. Перезагрузить страницу — данные сохранятся, потому что они в БД.

## Что реализовано

- Backend на FastAPI, PostgreSQL через SQLAlchemy.
- Модели: товары, офферы (ссылки на маркетплейсах), история цен.
- API: CRUD товаров, добавление/удаление офферов, обновление цены оффера.
- Сортировка по цене, рейтингу, приоритету, дате добавления.
- Группировка по диапазонам цены, по рейтингу, по приоритету, по
  признаку «пора брать».
- Фильтры по приоритету, диапазону цены, минимальному рейтингу,
  признаку «пора брать», поиск по названию и заметке.
- Целевая цена: если минимальная цена среди офферов ≤ целевой,
  товар помечается бейджем «пора брать».

## Ограничения

- Цены вводятся вручную. Автоматический парсинг маркетплейсов не
  реализован: публичный API Wildberries блокирует запросы без
  антибот-токена, у Ozon и Яндекс Маркета публичного API для
  покупателей нет.
